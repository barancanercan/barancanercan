- Shipped end-to-end systems across political intelligence, social media analytics, and historical document processing
- Conducted a 360-experiment factorial study comparing ReWOO / CoT / ReAct / Reflexion (ANOVA + scipy) — *orchestration strategy matters more than model size*
- Published [`vcsx`](https://pypi.org/project/vcsx) on PyPI: AI coding environment CLI for 10 tools including Claude Code, Cursor, and Gemini CLI
- Built a 98.8% accurate election forecasting model at 5M+ population scale (2024 Turkish Local Elections)
- Active technical writer on [Medium](https://medium.com/@barancanercan) — empirical LLM research & multi-agent architecture
